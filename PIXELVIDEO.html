PANDUAN SETUP SUPABASE STORAGE (PUBLIC)

LANGKAH 1: BUAT PROYEK SUPABASE

Buka supabase.com, masuk/daftar gratis, lalu klik New Project.

LANGKAH 2: BUAT BUCKET PUBLIC

Buka menu Storage di sidebar kiri → klik New Bucket → beri nama videos → aktifkan toggle Public bucket → klik Save.

LANGKAH 3: ATUR POLICY IZIN UPLOAD (RLS)

Di menu Storage → Policies pada bucket videos, tambahkan policy baru agar aplikasi web dapat mengunggah video tanpa login:

-- Jalankan di SQL Editor Supabase jika ingin cepat:
CREATE POLICY "Izinkan Upload Publik" ON storage.objects
FOR INSERT TO anon WITH CHECK (bucket_id = 'videos');

CREATE POLICY "Izinkan Baca Publik" ON storage.objects
FOR SELECT TO anon USING (bucket_id = 'videos');

LANGKAH 4: SALIN API KEYS

Buka Project Settings → API. Salin Project URL dan anon public key, lalu tempelkan ke Panel 1 di aplikasi ini!
