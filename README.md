# SKY WARRIORS 3D
**Simulasi Penerbangan & Pertempuran Udara 3D HD (Android & PC)**

## Fitur Utama
1. **Grafis 3D HD Realistis**: Mesin rendering WebGL 3D ringan dengan dukungan resolusi hingga Full HD (`1920×1080`), pencahayaan matahari dinamis, refleksi logam, lautan bergelombang, kepulauan, pegunungan, awan 3D, serta pangkalan udara lengkap dengan landasan pacu.
2. **5 Model Pesawat Tempur 3D Nyata**:
   - **F-16 Fighting Falcon**
   - **F-22 Raptor**
   - **F-35 Lightning II**
   - **Su-57 Felon**
   - **Eurofighter Typhoon**
3. **5 Mode Permainan**:
   - *Free Flight* (Terbang Bebas)
   - *Training* (Latihan Penerbangan & Tembak)
   - *Air Combat* (Pertempuran Udara 4v4)
   - *Mission Mode* (5 Misi Kampanye Taktis)
   - *Survival* (Bertahan Menghadapi Gelombang Musuh)
4. **3 Sudut Pandang Kamera**:
   - *Third Person* (Jarak kamera dapat diatur)
   - *First Person* (Kokpit lengkap dengan HUD hijau realistis)
   - *Cinematic* (Kamera sinematik dinamis)
5. **100% Gratis & Offline-Ready**: Semua pesawat dapat dimainkan secara gratis tanpa paywall, progres tersimpan otomatis (`localStorage`), serta berjalan lancar tanpa koneksi internet.

## Cara Menjalankan
- **Di Android**: Ekstrak file ZIP, buka `index.html` menggunakan browser modern (Google Chrome / Samsung Internet / Kiwi Browser) atau jalankan melalui server lokal (seperti Termux `python3 -m http.server 8080`). Putar layar ke mode **Landscape** untuk pengalaman terbaik.
- **Di PC / Laptop**: Ekstrak file ZIP dan buka `index.html` di Chrome, Edge, atau Firefox.

## Kontrol Permainan
- **Layar Sentuh (Android/Tablet)**:
  - **Joystick Kiri**: Arah pesawat (Naik, Turun, Belok/Roll Kiri & Kanan)
  - **Slider Throttle**: Mengatur kecepatan mesin & Afterburner
  - **Tombol Kanan**: `FIRE` (Meriam Vulcan), `MSL` (Rudal Terpandu), `FLARE` (Suar Pengecoh), `ROLL` (Manuver Menghindar), serta tombol cepat `UP / DOWN`
  - **Atas Kanan**: Ganti Kamera (`CAM`) & `PAUSE`
- **Keyboard (PC)**:
  - `W / S` atau `Panah Atas / Bawah`: Pitch (Turun / Naik)
  - `A / D` atau `Panah Kiri / Kanan`: Roll & Belok
  - `Shift / Ctrl`: Tambah / Kurangi Kecepatan (Throttle)
  - `Spasi`: Tembak Meriam (Gun)
  - `E` atau `Enter`: Luncurkan Rudal (Missile)
  - `F`: Lepas Flare
  - `Q`: Manuver Barrel Roll
  - `C`: Ganti Sudut Kamera
  - `P` atau `Esc`: Pause
